# SEVEN ROOTS | African Botanical Oral Care

Production-ready static launch site for the **SEVEN ROOTS** pre-launch collection.

## Live site

[msorsor1956.github.io/seven-roots-botanical-oral-care](https://msorsor1956.github.io/seven-roots-botanical-oral-care/)

## Experience

- Responsive editorial storefront for mobile, tablet, and desktop
- Dependency-free Canvas 360° product viewer with three pack variants
- Assembled and exploded product states with selectable component details
- Drag, swipe, keyboard, zoom, reset, and auto-rotation controls
- Reduced-motion support plus static and no-JavaScript fallbacks
- Botanical, sourcing, safety, and claims-discipline guidance
- Device-local format preference; no checkout or personal-data collection

## Run locally

No build step or package installation is required.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The `pages.yml` workflow deploys the repository root to GitHub Pages whenever `main` is updated. The site intentionally uses relative asset paths so it works at the project Pages URL.
